### 2.3 3D View Feature Enhancements (Client Feedback)
Matt suggested the following additions to match native mXrap behavior:
1. **Marker Size Interpolation (Min/Max Ramp):**
   * Instead of a single scale slider, configure **Min Marker Size** and **Max Marker Size** fields.
   * Marker sizes should interpolate linearly across the data range (e.g., local magnitude $M_L$).
   * Allow users to **invert** the scale (e.g., small $M_L$ values map to large markers, and large $M_L$ values map to small markers).
   * If no "Size by" property is selected, default to the average of the Min and Max sizes.
2. **XYZ Orientation Gizmo:**
   * Add a coordinate axis indicator in the bottom-left corner to assist user spatial orientation.
3. **Dynamic Grid (Nice-to-Have):**
   * Grid should only display when the camera is in **orthogonal projection mode** and aligned strictly down one primary axis (e.g., looking directly at the $XZ$ or $YZ$ plane).
   * The grid should automatically disappear when the camera is tilted/rotated into a perspective angle.
   * Aim for ~6 to 8 dynamic grid lines that adjust subdivision density on zoom.

### 2.4 Chart Module Requirements (Magnitude-Time Chart Walkthrough)
Matt shared his screen to demonstrate how charts are structured in mXrap and how they correspond to configuration files:
* **Multiple Axes Support:**
  * Demonstrated a chart with three defined axes: **Bottom** (Date/Time), **Left** (Local Magnitude $M_L$), and **Right** (Cumulative Events).
  * Support for **Logarithmic scales** (e.g., $\log_{10}$ scale for cumulative event counts).
* **Series Display & Controls:**
  * Each series can toggle points (magnifying glass icon) and/or lines independently.
  * Default visibility flags (`pointsVisible: false/true`, `linesVisible: false/true`) control initial load states.
* **Line Styling & Coloring:**
  * Support for **override colors** (solid line color).
  * If not overridden, line segments interpolate color dynamically based on underlying event values and the color legend.
* **Grouping & Ordering:**
  * Lines default to plotting in ascending order along the X-axis, but can accept a specified column for arbitrary/circular plot orders.
  * `groupBy` parameter allows splitting a single series into multiple distinct line segments based on categorical column values.
* **Interactivity Clarification:**
  * **Static vs. Dynamic Data:** Data will be pre-filtered prior to export; the web viewer does **not** need to handle real-time data filtering.
  * Dynamic axis rescaling when series are toggled is a nice-to-have; maintaining fixed axis bounds based on the full dataset is acceptable for MVP.
